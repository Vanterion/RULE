# VANTERION RULES

A bilingual (Thai / English), responsive community rules website for the VANTERION GROUP Discord server.

## Files

- `index.html` — page structure and metadata
- `style.css` — responsive dark theme and layout
- `script.js` — bilingual content, rule rendering, and copy interaction

## Discord

[Join VANTERION GROUP](https://discord.gg/F7bA8V4Rqj)

## Deploy

This is a static website and can be deployed using Cloudflare Workers Static Assets or Cloudflare Pages.

For a Cloudflare Worker with static assets, configure the assets directory to the repository root and deploy with Wrangler.
